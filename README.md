# СТОП-КАДР — сверка видеоряда со сценарием

Проект по [PRD.md](PRD.md). Два прототипа.

Сайт: https://aruzhanrakhimova.github.io/stop-kadr/ (OCR-проверка: https://aruzhanrakhimova.github.io/stop-kadr/video-text-qa.html)

## `video-text-qa.html` — вариант Б, OCR без ИИ (основной инструмент)

Сверяет текст на экране (титры, плашки) с текстом сценария.

1. Откройте файл двойным щелчком в Chrome, Edge или Firefox.
2. Загрузите видео, вставьте сценарий, при необходимости выберите область титров (например, «Нижняя треть»).
3. Нажмите «Проверить видео». При первом запуске нужен интернет: движок Tesseract.js и языковые пакеты (≈ 15–25 МБ) скачиваются с cdn.jsdelivr.net и потом кэшируются браузером. Само видео никуда не отправляется.
4. Отчёт: таймлайн, карточки с таймкодами, экспорт в `.md` и `.csv` (разделитель `;`, открывается в Excel).

Вердикты:
- **Совпадает** — схожесть по словам (коэффициент Дайса) ≥ 60 % и нет пословных расхождений.
- **Неточное совпадение** — схожесть 30–60 %, **или** схожесть высокая, но в титре есть слово, которое OCR прочитал уверенно (≥ 75 %) и которое отличается от сценария (`Иванов → Иванова`) или в сценарии отсутствует.
- **Не найдено в сценарии** — схожесть < 30 %.

Все пороги настраиваются в блоке «Точная настройка». Кнопка «Пересверить со сценарием» пересчитывает сверку после правки сценария без повторного OCR.

## `video-qa.html` — вариант А, смысловая сверка с ИИ

Опубликован как Claude Artifact: https://claude.ai/artifact/EQ1foX5hA6zHd5uh8WRttN

Сценарий делится на N фрагментов пропорционально длине текста; из середины каждого диапазона вырезается кадр, и Claude оценивает соответствие кадра фрагменту и проверяет титры. Каждая контрольная точка — один запрос за счёт квоты пользователя. Файл работает только внутри claude.ai: локально он показывает пример отчёта, но запустить проверку не даст.
